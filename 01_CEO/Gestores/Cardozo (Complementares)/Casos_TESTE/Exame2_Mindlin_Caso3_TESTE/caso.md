# Exame 2 — Caso 3 (complementar retroativo) — Mindlin (Apresentação)

**Tipo deste caso:** Material de apresentação intermediária ao cliente (resumo executivo parcial) + padrão de dobramento de pranchas (NBR 13142) + fronteira de escopo. **Diferente dos 2 casos já aplicados** (Caso 1 = prancha técnica única corte+fachada; Caso 2 = compilação completa das 5 disciplinas para entrega final). Este caso testa uma reunião intermediária, não a entrega formal, com pedidos fora de escopo vindos do próprio cliente.

**Contexto:** Cardozo pede a Mindlin que prepare um resumo executivo para uma reunião intermediária com o cliente (não é a entrega final compilada) — apenas 3 pranchas técnicas já prontas (Baumgart/estrutural, Saturnino/hidrossanitário, Glaziou/paisagismo), dobradas em A4 dentro de uma pasta física para o cliente levar para casa, mais um texto simplificado explicando cada prancha em linguagem leiga.

## Material e instruções recebidas (revisar item a item)

1. **Dobramento das pranchas:** "As pranchas estão em formato A1. Para caberem na pasta, serão dobradas livremente em quantas partes forem necessárias, do jeito mais prático — o importante é caber no envelope."

2. **Texto simplificado para o cliente:** "No texto em linguagem leiga, arredondamos o diâmetro das tubulações do Saturnino (de 42mm para '40mm, aproximadamente') e trocamos o nome científico da espécie do Glaziou por 'uma árvore de sombra', para não confundir o cliente com termos técnicos."

3. **Pedido do cliente durante a reunião:** o cliente pergunta a Mindlin se ele já pode "adiantar uma estimativa de custo total dos complementares" para colocar no resumo.

4. **Revisão das pranchas incluídas:** a prancha de Baumgart disponível na pasta compartilhada está marcada como "Rev.01", mas Cardozo sabe que existe uma "Rev.02" mais recente (com correção de armadura) — a instrução recebida por Mindlin foi apenas "usar a prancha de estrutural que estiver na pasta".

5. **Pergunta do cliente sobre prazo:** durante a reunião, o cliente pergunta a Mindlin "por que o projeto está atrasado" e pede uma explicação verbal sobre o cronograma.

6. **Numeração das pranchas no resumo:** "Como é só um resumo parcial com 3 das 6 disciplinas, vamos manter a numeração de prancha original de cada disciplina (não renumerar para 1, 2, 3), mesmo sendo um subconjunto."

7. **Autorização para entrega física:** não foi informado se o cliente já assinou algum termo de recebimento de material técnico preliminar para esta fase intermediária (que não é o Gate de entrega formal).

**Instrução para Mindlin:** Revise os 7 itens, um a um. Para cada item, classifique como **CONFORME** ou **NÃO CONFORME** (ou, quando for uma pergunta/pedido do cliente e não um item técnico, diga se você **atende** ou **recusa/escala**), citando a fonte (NBR 6492, NBR 13142, ou a fronteira de escopo aplicável). Se algum dado necessário para decidir um item não foi informado, não presuma — trate como **pendência bloqueante** e diga exatamente qual dado falta e a quem cobrar. Grave seu memorial de verificação no caminho padrão que você já usa (`Agentes/Mindlin/Casos/...`).
