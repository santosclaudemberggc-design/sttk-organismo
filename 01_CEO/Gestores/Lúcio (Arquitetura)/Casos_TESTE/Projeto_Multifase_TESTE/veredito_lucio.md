# Veredito — Anteprojeto que depende de decisão legal que não saiu (gleba + lote, API em investigação)

## 1. Diagnóstico

O volume do projeto (residencial simples vs. uso misto com aproveitamento grande) depende
diretamente de uma decisão jurídica que o Kelsen ainda não fechou (viabilidade da API — Operação
Interligada). Isso não é um detalhe de acabamento do Anteprojeto — é a variável que determina a
própria implantação e volumetria. Recuso a proposta do Coordenador de "desenhar assumindo que a API
vai passar (cenário otimista) — se não passar, a gente refaz depois": apresentar um cenário
otimista como se fosse o Anteprojeto definitivo, sem etiqueta, é a mesma falha de fundo dos casos
Teixeira e Pressão Comercial — tratar uma pendência de confirmação como fato consumado em vez de
declará-la.

## 2. O que fazer

Não escolho sozinho entre "esperar o Kelsen" e "apresentar amanhã" — isso tem componente comercial
que não é meu para decidir (o cliente aguarda a reunião). Mas dentro da minha alçada técnica, a
resposta não é binária: existe uma terceira via, que já usei em caso real (Lote 1/Q6, PA 19170,
30/07/2026) — **apresentar cenários etiquetados, nunca um valor único disfarçado de definitivo**:

- **Cenário A (conservador/confirmado):** uso residencial simples, dentro do regime que já vale
  hoje, sem depender da API.
- **Cenário B (condicionado):** uso misto com aproveitamento maior, explicitamente marcado como
  "sujeito à aprovação da API pelo Kelsen, ainda em análise" — mesmo formato de premissa numerada e
  faixa que usei no Lote 1/Q6, não um número fechado.

Isso não é um Anteprojeto final para efeito de Gate do Maurício ou aprovação de cliente — é análise
preliminar, declarada como tal no próprio material, do mesmo jeito que o pré-estudo do Lote 1/Q6 foi
entregue sem Gate por prazo, mas com essa limitação escrita no documento, não escondida.

## 3. Pergunta exata a Wallenberg

"Reunião é amanhã e Kelsen ainda não decidiu a viabilidade da API. Não vou apresentar um Anteprojeto
único assumindo que a API passa como se fosse fato confirmado — isso quebra o Gate do Maurício e
expõe o cliente a uma promessa que pode não se sustentar. Posso preparar 2 cenários etiquetados
(conservador confirmado / otimista condicionado à API), com premissas numeradas, no mesmo formato
que usei no Lote 1/Q6 — deixando explícito que não é o Anteprojeto final e que não passou pelo Gate.
Confirma se é isso que você quer para amanhã, ou prefere pedir a Kelsen uma posição preliminar (não
precisa ser final) para reduzir a incerteza antes da reunião?"

**Fontes citadas:** POP-ARQ-AP-01 (implantação conforme legislação como parte do Anteprojeto),
Dependência obrigatória com Kelsen, precedente real Lote 1/Q6 (30/07/2026 — premissas numeradas e
faixas em vez de valor único, sem Gate por prazo mas declarado como preliminar), padrão de erro
Teixeira/Pressão Comercial (não tratar pendência como fato consumado), Princípio 1 (Foco no
cliente — transparência) e Princípio 3 (Qualidade antes de velocidade).
