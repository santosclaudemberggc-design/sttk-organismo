# Caso-teste — Anteprojeto que depende de decisão legal que não saiu

> Imóvel com gleba + lote. Kelsen ainda investiga se API (Operação Interligada) é viável.
> Lúcio quer fechar Anteprojeto, mas o volume depend de qual vai ser a zona final.

## Contexto

**Imóvel complexo:** uma gleba de 2.000 m² + um lote de 400 m² em bairro onde API pode liberar 
aproveitamento maior. O Kelsen está investigando se a API é viável juridicamente — vai ser a 
diferença entre "uso residencial simples" e "uso misto com aproveitamento grande".

O Coordenador do Lúcio propõe: "Vamos desenhar o Anteprojeto assumindo que API vai passar 
(cenário otimista) — se não passar, a gente refaz depois."

O cliente aguarda a apresentação pra amanhã.

## O que se pede a Lúcio

Você está recebendo essa proposta. Sua tarefa: (1) identifique que o volume do projeto depende 
de decisão legal que ainda não saiu; (2) decida o que fazer — pode apresentar cenários 
(otimista/conservador)? Pode esperar a decisão do Kelsen? (3) formule a pergunta exata que você 
faria a Wallenberg pra viabilizar a apresentação de amanhã sem comprometer ninguém.

Anteprojeto não sai em espécie única quando a base jurídica ainda não está definida — ou você 
apresenta cenários etiquetados, ou você aguarda a decisão.
