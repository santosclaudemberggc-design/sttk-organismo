Definido por Claudemberg em 20/07/2026, durante o detalhamento do Lúcio (Gestor Arquitetura, ver [[sttickler_ceo_wallenberg]]).

**O marco:** assim que o sistema **VITRUVIUS** (a integração com Revit — já existe como conjunto de ferramentas `mcp__vitruvius__*` neste ambiente: criar parede, piso, sala, porta, janela, nível, cotar, etc., mas ainda não confirmado como "100% pronto" por Claudemberg) estiver totalmente concluído, o organismo começa a **testar a realização de projetos de verdade via agentes** — ou seja, o Coordenador de Projeto Arquitetônico de Lúcio deixa de só coordenar o arquiteto parceiro e passa a produzir cada etapa diretamente dentro do Revit.

**Por quê isso importa:** hoje a capacidade de Arquitetura é limitada a "coordena, não produz" justamente por essa lacuna de engenharia (ver [[sttickler_revit_capacidade]]). Este marco é a condição de virada — não é uma data, é um estado ("Vitruvius 100% pronto") a ser confirmado por Claudemberg quando chegar lá.

**Como aplicar:** não antecipar essa capacidade na proposta do Lúcio nem em nenhum outro Gestor como se já estivesse disponível. Quando Claudemberg sinalizar que o Vitruvius está pronto, isso vira o gatilho pra montar o primeiro teste real (provavelmente via `D:\010_PESQUISADOR DE TESTES`, mesmo padrão usado para validar o Kelsen/Hely).
